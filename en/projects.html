11402_CS351_Project0: Two Sum

Tech Stack: C++, CMake, GitHub Actions, Jira, Git, GitHub Copilot | View GitHub Repository ↗

Two Sum is a classic algorithm problem that aims to find two numbers in an array whose sum equals a target value. This project implements the common Hash Table and Array solutions and compares their time and space complexity.

During development, AI-assisted programming was used, and the project included learning how to manage work with Jira, version control with Git, and building an automated workflow with CMake and GitHub Actions.

IN314 Introduction to Image Processing

Final Project: Invisible Watermark

Tech Stack: Python, DFT, QIM | View GitHub Repository ↗

This project is used to hide watermarks in images, using DFT and QIM techniques to embed and extract invisible watermarks.

The embedded watermark image could not be successfully extracted after lossy compression (such as JPEG). In the future, error correction codes (such as Hamming Code) may be added to improve robustness.
