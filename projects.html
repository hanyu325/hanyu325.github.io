11402_CS351_Project0: Two Sum

Tech Stack：C++, CMake, GitHub Actions, Jira, Git, GitHub Copilot | 查看 GitHub 儲存庫 ↗

Two Sum 是一道經典的演算法問題，目標是在陣列中找出兩個數字，使其總和等於指定目標值。本專案實作了 Hash Table 與 Array 兩種常見解法，並比較其時間與空間複雜度。

在開發過程中，嘗試使用 AI 輔助程式開發，並學習以 Jira 進行專案管理、使用 Git 進行版本控制，以及結合 CMake 與 GitHub Actions 建立自動化建置流程。
